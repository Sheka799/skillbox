# Интернет магазин электроники

Учебный проект Vue.js приложения - полнофункциональный интернет-магазин с каталогом товаров, системой фильтрации, корзиной покупок и оформлением заказов.

## 🎯 Описание

Это приложение электронной коммерции, разработанное как учебный проект для изучения Vue.js, Vue Router и Vuex. Проект демонстрирует основные концепции построения современных веб-приложений на базе Vue.

## ✨ Основные возможности

- **Каталог товаров** - просмотр всех доступных товаров
- **Фильтрация** - фильтрация по категориям и цветам
- **Детальная страница товара** - полная информация о товаре
- **Корзина покупок** - добавление/удаление товаров, просмотр количества
- **Оформление заказа** - форма с валидацией данных
- **История заказов** - отслеживание информации о заказах
- **Пагинация** - навигация по товарам
- **Адаптивный дизайн** - корректное отображение на всех устройствах

## 🛠 Технологический стек

- **Frontend Framework:** Vue.js 2.6
- **Routing:** Vue Router 3.5
- **State Management:** Vuex 3.4

## 📁 Структура проекта

```
src/
├── App.vue                 # Основной компонент приложения
├── main.js                 # Точка входа
├── config.js               # Конфигурация приложения
├── eventBus.js             # Event Bus для коммуникации компонентов
├── components/             # Переиспользуемые компоненты
│   ├── ProductItem.vue     # Карточка товара
│   ├── ProductList.vue     # Список товаров
│   ├── ProductFilter.vue   # Фильтр товаров
│   ├── CartItem.vue        # Товар в корзине
│   ├── CartIndicator.vue   # Индикатор корзины в шапке
│   ├── BasePagination.vue  # Пагинация
│   └── BaseForm*           # Компоненты форм
├── pages/                  # Страницы приложения
│   ├── MainPage.vue        # Главная страница каталога
│   ├── ProductPage.vue     # Страница товара
│   ├── CartPage.vue        # Страница корзины
│   ├── OrderPage.vue       # Страница оформления заказа
│   ├── OrderInfoPage.vue   # Страница информации о заказе
│   └── NotFoundPage.vue    # Страница 404
├── router/
│   └── index.js            # Конфигурация маршрутов
├── store/
│   └── index.js            # Vuex store (состояние приложения)
├── data/                   # Данные приложения
│   ├── products.js         # Список товаров
│   ├── categories.js       # Категории
│   └── colors.js           # Цвета
├── helpers/                # Вспомогательные функции
│   ├── numberFormat.js     # Форматирование чисел
│   └── gotoPage.js         # Навигация по страницам
└── mixins/
    └── formFieldMixin.js   # Миксин для работы с полями формы
```
